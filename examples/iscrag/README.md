# iscrag

The held-out benchmark from "RAG Deserves an Index" (arXiv 2608.20845), rerun with Factoid in place of the original ISC
pipeline: 500 MediaSum transcripts and 499 questions, with the paper's answer prompt, judge prompt, source rendering,
and token budgets.

Not built yet. Data stays out of git: MediaSum is research-use only and must not be redistributed, and the questions
come from the ISC-RAG study database.
