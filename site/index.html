Turn documents into cited, self-contained facts.

Factoid is an open-source Python framework that compiles prose and tabular documents into short, pronoun-free facts tied to exact source quotes and linked entities. As new documents arrive, it retires outdated facts, merges duplicates, and flags contradictions.

Requires Python 3.13+ and uv

Domain framework

Map your domain with plain Python classes

Subclass ProseDocument, StructuredDocument, Fact, FactTrait, Entity, and Settings. Subclassing is the declaration, with no registration step and no single config file. Every step exposes before_ and after_ hooks. 

from factoid import Identity, Ignore, Property, ProseDocument, StructuredDocument, Text

class Contract(ProseDocument):
    """A signed contract or an amendment to one."""
    chunk_size = 4000
    chunk_overlap = "15%"
    situate = True

    @property
    def source_datetime(self):
        return self.metadata.get("signed_at")

class ContractRegister(StructuredDocument):
    """The data room's list of the target's contracts."""
    row_entity = Agreement
    key = "contract_id"
    when = "updated_at"
    columns = {
        "contract_id": Identity(Agreement, "contract_id"),
        "counterparty": Property(Agreement, "counterparty"),
        "annual_value": "Agreement {contract_id} is worth ${annual_value} a year.",
        "notes": Text(),
        "internal_ref": Ignore(),
    }
Prose documents segment, chunk, situate, and extract. Structured documents ingest CSV, JSONL, JSON arrays, and records with zero model calls on templated cells. 
from factoid import Fact, FactTrait, Noul, judge

class ConsentRequired(FactTrait):
    """A named party must approve an action before it happens."""

class LiabilityCap(FactTrait):
    """A limit on how much a party can owe."""
    threshold = 0.8
    examples = ["Orion's liability under the Vega supply agreement is capped at $1M."]

    @classmethod
    @judge(states_amount=Noul("Does it state an amount of money?"))
    def decide(cls, fact, judgments):
        return judgments.liability_cap > cls.threshold and judgments.states_amount > 0.5

class SourceFact(Fact):
    """What a contract, a client, or the other side says."""
    traits = [ConsentRequired, LiabilityCap]
A fact has no typed slot; the sentence carries the meaning. Traits and time properties are assessed together in a single decision request. 
from factoid import Entity

class Company(Entity):
    """A company that is a party to a deal or a contract."""
    unique_keys = ["domain"]
    jurisdiction: str

class Agreement(Entity):
    """One contract and its amendments, as a whole."""
    unique_keys = ["contract_id"]
    counterparty: str
    governing_law: str

class Person(Entity):
    """A lawyer, a client contact, or someone at the other side."""
    unique_keys = ["email"]
    role: str
    link_threshold = 0.85
Linking stops at the first sure step: exact ID, unique key, single match in the document, single match in the store, or a decision-model check. Untyped entities are kept and linked. 
from factoid import Model, Settings
from factoid.exports import Parquet, Turbopuffer
from factoid.stores import Sqlite

class Project(Settings):
    store = Sqlite(path=".factoid/acme.db")
    models = {
        "choose": Model("typesafe/jev-1.13.0"),
        "generate": Model("fireworks/glm-5p3-flash"),
        "embed": Model("fireworks/qwen3-embedding-8b"),
        "rerank": Model("fireworks/qwen3-reranker-8b"),  # optional
    }
    exports = {
        "warehouse": Parquet("s3://my-bucket/facts/"),
        "search": Turbopuffer(namespace="acme-facts"),
    }
Search needs no external service to start: by default, Factoid uses a local SQLite index with FTS5 BM25 and exact vector search. Turbopuffer is optional.
01

Classify, segment, chunk, and situate

Prose splits into passages without breaking paragraphs or speaker turns. Optional situate writes a one- or two-sentence context for each chunk before extraction.

02

Extract with deterministic quotes

The extractor resolves relative dates against source_datetime and cites passage numbers. Factoid's code attaches the exact quote, speaker, and timestamp.

03

Evaluate and repair

DecisionFloors checks six yes-or-no probabilities in one call: grounded, attribution, self_contained, atomic, useful, and distinct. Repairable failures get one rewrite and are checked again.

04

Assess, link, and resolve on write

Assigns traits and time properties, links entities on a five-step ladder, and resolves each new fact against stored facts sharing an entity. Every change writes to SQLite and its event log.

State and history

Fact lifecycle, time, and contradictions

For each new fact, Factoid gathers stored facts that share an entity and asks the decision model one question with six answers: duplicate, supersedes, ends, corrects, contradicts, or unrelated.

current

Active fact representing the latest state. Returned in default queries and weighted by validity.

superseded

Replaced by a newer value that took effect later. Remains searchable for as_of queries.

ended

A state that stopped without a replacement value. Held valid until its end date.

corrected

Marked wrong from the start by a later correction, with the link recorded in the event log.

contradicted

Disagrees with another stored fact. Both sides stay linked and appear together in search results.

replaced

Old fact changed or dropped when its source document was re-ingested as a new revision.

retracted

Explicitly withdrawn by a person or agent, such as when settling a contradiction.

Time properties on every fact

Each fact records valid_from (future dates allowed), expires ("never", "estimated", or "at_deadline"), valid_until when stated, and a lifetime probability distribution from an hour to longer than a few years. Search weights scores by the chance a fact still holds at as_of.

valid_from expires valid_until lifetime

Settling contradictions and caching calls

Contradictions settle automatically when newer evidence supersedes, ends, or corrects one side, or manually via factoid contradictions settle, HTTP, or MCP with a logged reason. Model calls replay from .factoid/calls.db so reruns cost nothing, or can be restricted with call_log = "metadata" or "none".

Read, serve, and export

CLI, Python API, HTTP server, MCP, and exports

People, agents, and data pipelines share the same SQLite store, hybrid retrieval (BM25 + vector, with optional reranking), and as_of temporal queries. Both factoid serve and factoid mcp use only the Python standard library.

  • One command inside projects: factoid finds your project environment automatically; no uv run needed.
  • Ingest and inspect: Run ingest, facts list, search, read, stats, entities list, and contradictions.
  • Built-in eval harness: Compare prompts, models, or fact eval chains on the same documents with factoid eval --vary.
  • Structured dry runs: Use factoid struct inspect, parser, and try before importing CSV or JSONL files.
factoid init
factoid keys set
factoid doctor
factoid ingest ./sample_docs
factoid search "Vega liability cap" --as-of 2027-02-01
factoid contradictions settle FACT_A FACT_B --keep FACT_A --reason "signed copy"
factoid eval --vary fact_evals=none,decision_floors
  • Embed as a library: Pass your classes to Factoid(...) and ingest text or files in process.
  • Entity and trait queries: Look up entities by typed properties with where(), fetch linked facts, or inspect co-mentions with related().
  • Temporal and scoped search: Pass about=, as_of=, valid_at=, or search a single fact class such as CounselFact.search(...).
  • Source chunks: Search situated source chunks in their own namespace via Chunk.search(...).

  • Standard-library HTTP sidecar: factoid serve binds to 127.0.0.1:8765 by default. Set FACTOID_API_TOKEN for bearer auth on other hosts.
  • Read routes: GET /search, /facts, /facts/<id>, /entities, /entities/<name or id>, /documents/<id>, /contradictions, /events?after=N, /stats, and /health.
  • Write routes: POST /ingest and POST /contradictions/settle. Writes serialize while reads do not wait for them.
factoid serve --port 8765

  • MCP over stdio: factoid mcp exposes search_facts, read_fact, list_facts, find_entities, read_entity, stats, read_events, list_contradictions, settle_contradiction, and ingest_text. Pass --read-only to omit write tools.
  • Incremental Parquet export: Writes facts, entities, documents, and events locally or to S3 (with optional vectors=True for DuckDB, BigQuery, Databricks, ClickHouse, and Snowflake).
  • Incremental Turbopuffer export: Syncs vectors, BM25 text, traits, status, and validity dates from each export's own event cursor.

Research behind Factoid

Most of Factoid comes from internal research and production experience, and a smaller part builds on three published papers.

arXiv:2608.20845

RAG Deserves an Index: Why Ingest-Time Compilation Beats Query-Time Interpretation

Kyle Wild, Yusuke Takahashi, and Asako Uraki · 2026

Extracts single-claim sentences once at ingest time and checks each against its source passage. On 500 held-out interview transcripts, compiled claims scored 85.2% correct from about 2.2k reader tokens, against 72.5% from 16.3k.

arXiv:2609.29661

Ingest-Time Fact Compilation for Cost-Efficient and Reliable Question Answering over Revised Corpora

Kyle Wild, Yusuke Takahashi, and Asako Uraki · 2026

Resolves revisions, deletions, effective dates, and source authority once at ingest time. In its controlled experiment, the compiled path was right in 30 of 30 trials, against 1 of 30, at 12.89 times lower read cost.

Cost Scales with Change, Not Corpus Size: Incrementally Maintaining an Evolving Semantic Substrate

Yusuke Takahashi, Kyle Wild, and Asako Uraki · 2026

When documents are added or revised, incremental updates process only what changed, running 33.7 times cheaper than a full rebuild while producing the same result.
