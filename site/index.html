Factoid Framework

Factoid is an open-source Python framework that turns Documents into short, self-contained Facts and Entities, each tied to an exact location in the source document.

Factoid is early software (version 0.1.x), requires Python 3.13+, and uses the MIT license.

Install via uv Python 3.13+ required
$ uv tool install factoid

Domain Modeling and Extraction Pipeline

Factoid is a configurable framework where you map it to your domain by extending the Document, Fact, and Entity base classes.

domain_model.py Python 3.13+ 
from factoid import Document, Entity, Fact


class SourceContract(Document):
    """Domain document representing source text."""
    pass


class Counterparty(Entity):
    """Domain entity referenced across documents."""
    pass


class ContractualObligation(Fact):
    """Self-contained fact extracted from a specific document location."""
    pass
Subclass Document, Fact, and Entity to map custom domain objects.

Access Paths

People, agents, and data pipelines use these paths to query facts with semantic, BM25, and hybrid-reranked search, including "as of" queries for a past date.

Terminal Interface

CLI

Direct terminal access for engineers and automated shell scripts. Search the fact database interactively or emit structured JSON streams for shell pipelines.

Query capabilities:

  • Semantic vector retrieval
  • Exact BM25 keyword matching
  • Hybrid-reranked query mode
  • "as of" queries for past dates
CLI invocation factoid query "payment terms" --as-of 2024-01-01 --hybrid
Network Service

HTTP API

Standard REST API for backend services and data pipelines. Provides endpoints for ingestion, fact retrieval, entity graph traversal, and temporal status filters.

Query capabilities:

  • Semantic vector retrieval
  • Exact BM25 keyword matching
  • Hybrid-reranked query mode
  • "as of" queries for past dates
HTTP endpoint POST /v1/facts/search
{"query": "...", "as_of": "2024-01-01"}
Agent Protocol

MCP

Model Context Protocol server integration for AI assistants and autonomous agents. Gives language models native access to inspect cited facts and entities.

Query capabilities:

  • Semantic vector retrieval
  • Exact BM25 keyword matching
  • Hybrid-reranked query mode
  • "as of" queries for past dates
MCP tool definition mcp://factoid/query_facts?rerank=hybrid&as_of=...
ℹ
Unified retrieval engine: People, agents, and data pipelines share identical ranking and temporal precision across all three interfaces. Every query supports semantic, BM25, and hybrid-reranked search, including exact historical queries evaluated "as of" any past date.

Fact Lifecycle and Statuses

Every fact is a short, self-contained sentence devoid of filler and explicit in its language (no pronouns), linked to its exact source location and affected entities.

Status Lifecycle Meaning and Role Fact Set Behavior
current Active, verified fact that reflects the latest valid state extracted from source documents. Active in default queries
superseded Replaced by newer information introduced in a subsequent document. Historical queries only
ended The stated event, condition, or period has concluded according to source documents. Historical queries only
corrected Modified to resolve an extraction error or erratum identified in the source text. Archived with correction link
contradicted Conflicts with another recorded fact in the repository and has been flagged for disagreement. Flagged in query results
replaced Substituted due to structural changes, schema updates, or entity consolidation. Substituted by replacement fact
retracted Explicitly withdrawn by the publisher or author of the source document. Excluded from active state

Sentence Structure Mandate

In Factoid, each fact is recorded as an explicit, pronoun-free statement. Facts carry coordinate pointers back to the original source text alongside bidirectional links to all affected Entities. When new documents arrive, Factoid retires outdated facts, merges duplicate facts, and flags facts that disagree.

News Transcripts Evaluation and Example Applications

Empirical evaluation results demonstrate retrieval efficiency and precision on news transcripts.

Benchmark Dataset

News Transcripts (200 Questions)

On 200 questions about news transcripts, facts read at 512 tokens answered 0.92 right, plain chunks read at 2,048 tokens answered 0.87 right, and at 8,192 tokens the two are even.
